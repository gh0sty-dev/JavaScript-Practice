## 📁 JavaScript Practice Assignment

This repository contains 50 JavaScript coding exercises designed for hands-on practice. The questions range from beginner to intermediate level and cover:

* ✅ Basics (variables, functions, conditionals)
* 🔤 Strings (manipulation, reversal, palindrome, formatting)
* 🔢 Arrays (sorting, filtering, rotating, frequency count)
* 🧭 `map`, `filter`, `reduce` (functional programming)
* 🔁 Loops (patterns, sequences, number logic)
* 🧱 Object-Oriented Programming (classes, inheritance, encapsulation)
* 🔀 Mixed Concepts (combinations of above topics)

### 📄 Structure

Each exercise can be implemented in its own file, named like:

```
Exe_1.js
Exe_2.js
...
Exe_50.js
```

### 🚀 Getting Started

Clone the repo and start solving the exercises one by one. Use your favorite code editor (like VS Code) and node.js or the browser console to test your solutions.

```bash
git clone https://github.com/your-username/js-practice-assignment.git
cd js-practice-assignment
```
